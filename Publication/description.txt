Развлечения, видео и каталоги

Краткое описание
Madventure TV — приложение для Android TV: каталог фильмов по жанрам с поиском по названию и подробной карточкой. Всё управляется с пульта.

Основное описание
Madventure TV помогает быстро найти фильм на большом экране: выберите канал-жанр, найдите нужное название и откройте подробную информацию.

Возможности:
Заставка и вход: при запуске показывается заставка, затем экран входа с полями Email и Password. Если поля пустые, приложение попросит их заполнить.
Каналы по жанрам: Action, Comedy, Horror, Drama, Sci-Fi – переключайтесь между каналами одним нажатием.
Сетка карточек «My quests»: постер, название, год и кнопка Details, три карточки в ряд.
Поиск по названию: список выбранного канала фильтруется по мере ввода.
Карточка фильма: постер, год, длительность, рейтинг IMDb, жанр, режиссёр, актёры и сюжет.

Управление
Стрелки пульта – перемещение по карточкам и меню, OK – выбор, «Назад» – возврат к списку.
